# Питомец Финни 🦊

Мобильная игра о финансовой грамотности для детей 7–11 лет. Проект хакатона Департамента финансов Москвы.

Ребёнок заботится о лисёнке Финни и на практике осваивает базовые понятия финансовой грамотности:
**зарабатывай → трать с умом → копи → делись**.

## Игровой цикл

- **Заработать** — отвечай на вопросы о деньгах (нужды/желания, бюджет, банки, проценты) и получай монеты.
- **Магазин** — покупай еду (нужно) и игрушки (хочется) для Финни за монеты.
- **Дом** — корми и играй с Финни купленными вещами, следи за сытостью и радостью питомца.
- **Копилка** — откладывай монеты на цель; накопления сами понемногу растут («проценты»).
- **Награды** — открывай значки за накопления, баланс трат и серию дней подряд.

Прогресс хранится только локально на устройстве (Jetpack DataStore) — без бэкенда, без входа в аккаунт.

## Стек

- Kotlin, Jetpack Compose (Material 3), Navigation Compose
- Android Gradle Plugin 9.4 (Kotlin встроен в AGP, начиная с 9.0)
- kotlinx.serialization + DataStore Preferences для локального сохранения
- compileSdk / targetSdk 36, minSdk 26

## Сборка и запуск

Открой проект в Android Studio (Ladybug и новее) или собери из командной строки:

```bash
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`. Для запуска на подключённом устройстве/эмуляторе:

```bash
./gradlew installDebug
```

Юнит-тесты доменной логики (доступны без эмулятора):

```bash
./gradlew test
```

## Структура

```
app/src/main/java/ru/finnipet/app/
  data/      GameState (сериализуемое состояние) + GameRepository (DataStore)
  domain/    вопросы, товары магазина, цели копилки, значки, чистая игровая логика
  ui/        ViewModel, тема, переиспользуемые компоненты, экраны (Compose)
```
